# Kolkata Vegetation vs Built-up Analysis (NDVI & NDBI)

This project analyzes vegetation and built-up land cover in the New Town / Rajarhat area of Kolkata using remote sensing and GIS techniques in QGIS.

## Objectives

- Extract vegetation information using NDVI
- Identify built-up areas using NDBI
- Compare the spatial distribution of green cover and urban development
- Create professional thematic maps for portfolio presentation

## Data Used

- NDVI raster (GeoTIFF)
- NDBI raster (GeoTIFF)

## Software

- QGIS 3.44
- Remote sensing raster analysis tools

## Workflow

1. Load NDVI and NDBI rasters into QGIS
2. Apply suitable color symbology
3. Compare vegetation and built-up patterns
4. Design final layouts in QGIS Print Layout
5. Export thematic maps as PNG
